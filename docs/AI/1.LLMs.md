## Important resources

* [Kaggle](https://www.kaggle.com/) Google owned platform for data science and ML with 25 million community of AI enthusiasts sharing news, data and models. Includes a notebook platform like colabs. Competitions run regularly with significant prize money.  
* 🤗[HuggingFace](https://huggingface.co/) a huge open source community with hundreds of models, data and tools to make it easy to build NLP and ML systems. It's flagship library 'Transformers' provides pre-trained models supported by a broad ecosystem of data and tools and models. It's like the github for machine learning.
* [Lagchain](https://www.langchain.com) OSS Libraries for using models. It's a general-purpose framework for developing applications powered by LLMs. It provides tools for chaining together prompts, models, and external components like APIs or databases. LangChain is very flexible and has become a foundational library for building prototypes of LLM apps, retrieval-augmented generation (RAG) pipelines, and integrations with vector databases or external tools.
* [langGraph](https://www.langchain.com/langgraph) a framework designed for building stateful, multi-agent applications with large language models (LLMs). It uses the idea of graphs, where nodes represent agents or steps in a workflow, and edges define how information flows between them. This makes it particularly good for complex applications that require memory, coordination between multiple LLM “agents,” or branching logic. LangGraph focuses on long-running conversations, agent collaboration, and state management in a structured way.
* [Agno](https://github.com/agno-agi/agno). Similar to Langchain, a multi-agent framework, runtime and control plane. Built for speed, privacy, and scale.

### Core Concepts

#### Encoding

Encoding is the process of mapping words/word-fragments into a numerical representation that a Large Language model can process. One-hot encoding and Vector spaces are typically used. The mapping from a discrete space of words with distinct meaning to a continuous space of semantic meaning is subtle. However, it's key to applying predictive analytics to language.

* [Formal Aspects of Language Modeling](https://arxiv.org/abs/2311.04329) paper, Nov 23.

   Large language models have become one of the most commonly deployed NLP inventions. In the past half-decade, their integration into core natural language processing tools has dramatically increased the performance of such tools, and they have entered the public discourse surrounding artificial intelligence.

   Consequently, it is important for both developers and researchers alike to understand the mathematical foundations of large language models, as well as how to implement them.
   These notes are the accompaniment to the theoretical portion of the ETH Zürich course on large language models, covering what constitutes a language model from a formal, theoretical perspective.
